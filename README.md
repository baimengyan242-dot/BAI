## DeepSeek Memory Bridge

A native DeepSeek Harness plugin for local history archives, reviewed long-term memories and cross-session recall.

Version 0.2.2 provides a Chinese native DSH interface, selectable storage drives, verified migration and complete user guides. English project documentation remains available.
